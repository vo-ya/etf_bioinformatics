Teaching week 2

Students locate reads in a reference, score alignments with gaps, and interpret identity, query coverage, and E-values.

Preparation and scope

Students should understand a read, DNA strand direction, and estimated base-call confidence from week 1. Begin with their trimming results: shorter, more confident reads may be harder to place. All sequences are invented and unrelated to the fictional cultures. No live database account, installation, or network service is required for the class activities.

The class is 180 minutes, including a ten-minute break. Colab is separate 60–90-minute homework after class and before week 3. Explain dynamic programming conceptually in class; the homework supplies loops, traceback, and hints around the parts students complete. Index structures, FM/BWT internals, protein substitution-matrix derivations, affine-gap recurrences, and derivation or calibration of E-value statistics are beyond the required week. Use the E-value explorer to compare database sizes at a fixed score.

Alignment boundaries, one cell, and search cost

Slide 16 asks students to fit the complete read ACGT within TTACGTAA. Fitting consumes every read base while leaving reference flanks unpenalized; local may omit read ends. Both select the same region here, so ask which bases each objective requires, not just which result it produces. No fitting implementation is required.

Slide 18 uses the homework pair AC/AG. Explain boundaries 0, −2, −4 as accumulated gap costs. At D[2][2], diagonal 2−1=1 pairs C/G; above 0−2=−2 pairs C/−; left 0−2=−2 pairs −/G. The maximum is 1. Rows are reference prefixes and columns are read prefixes.

Slide 23 compares 150×3,000,000,000=450 billion interior cells with 150×300=45,000 for one candidate window. These hypothetical table counts exclude boundaries and candidate discovery. With c windows the interior work is c×45,000, plus discovery. Ask what useful region could be lost at the seed-filtering stage.

Activities and worked answers

The schedule includes seven activities. Project the controls or let pairs use them. Ask for a predicted result before changing a setting, then discuss any surprise. Slides link to the activities in another tab. In the score table, arrow keys move between cells; worked answers are available below the controls.

1. Place a read

Placement lab: in ATGCCATGACCTATGCCA, ATGCCA has starts [0, 12], CCATGA has [3], and shortened ATG has [0, 5, 12]. Try TGGCAT with reverse-complement search checked: its reverse complement matches starts 0 and 12. A palindromic query can produce two strand labels at one locus; the tool reports distinct start positions separately from strand-labelled matches.

2. Move a gap

Scoring lab: ACGT / A-GT gives 4 with +2/−1/−2. Left-justified ACGT / AGT- gives −2. The second pair compares ACGT / AGCT, always score 2, with A-CGT / AGC-T, score 6 − 2×gap cost. Costs 1, 2, and 3 respectively favour the gapped candidate, tie, and favour the ungapped candidate. These are comparisons of two candidates, not proof that no other optimum exists. Return to cost 2 before moving on.

3. Change alignment scope

Alignment lab: TTACGTAA / GGACGTCC gives global score 4, 50% identity, 100% query coverage. Local ACGT / ACGT scores 8, 100% identity, 50% coverage. Its intervals are [2, 6) in both sequences: zero-based, end excluded. ACGT / AGT gives global score 4. AAA / CCC has best local score 0 and no positive-scoring region; identity is undefined for an empty alignment.

Start the table with the one-gap example. Select cell (1,1): diagonal 2, above −4, left −4. Explain why the maximum is 2. Show a boundary cell, then switch to local to discuss restarting at zero. The live table uses reference rows and query columns. The separate original SVG states its own row/column convention and uses GATTACA/GCATGCA, maximum 5; do not mix these examples.

4. Audit a search shortcut

Search lab: query ACGTTGCA. At k = 4, Exact, Near, and Short region pass. Enable the audit to see that Interrupted also has a useful local score despite having no exact 4-mer. All five candidates pass at k = 2; only Exact passes at k = 6. The demonstration filters whole candidate sequences and then computes exact local alignment; it is not a complete BLAST implementation or a performance benchmark.

5. Count the exact comparisons

Exact-search stepper (10 minutes): query TACAGA in GATTACAGATTACA. With “Exit at first mismatch” selected, starts 0, 1, 2, and 3 use 1, 1, 2, and 6 comparisons respectively, totalling 10 to the first hit at 3. Continue to distinguish first-hit work from a complete search. AAA in AAAAA must retain overlapping hits at 0, 1, and 2.

6. Build and trace a local table

Alignment animator (10 minutes): choose reference GATTACA, query GCATGCA, +2/−1/−2. Invite a prediction for a cell before revealing it, then trace from a maximum to zero. The maximum is 5; reference TACA against query TGCA gives 2 − 1 + 2 + 2. Both occupy one-based inclusive positions 4–7. Ask why the trace stops at zero instead of necessarily reaching the table origin.

On slide 27, distinguish query coverage (a percentage of the query in a search hit) from average coverage (mean mapped read depth over a reference, including zero-depth positions). Three four-base reads fully aligned within 12 reference bases give 1× mean depth. Ask whether that guarantees every position is covered. It does not: placing all three reads over the same four positions gives depths 3 at four positions and 0 at eight positions, still averaging 1×. Slide 28 draws both placements and their per-position depths, alongside a separate hit covering six of twelve query bases (50%). Ask students to calculate each metric from its own diagram. This prepares the mean-depth and covered-fraction comparison in Week 3.

7. Change the search space

E-value explorer (10 minutes): fixed bit score 40, effective query length 100, effective database length 1,000,000 gives E ≈ 0.00009095 in the simplified model. Increasing database length tenfold multiplies E by ten. Increasing score by one bit at fixed lengths halves E. Ask students to calculate the factor of change before moving the control. The activity provides no universal significance cutoff.

The plot and explorer use synthetic effective search spaces, not current named database sizes. These values are not E-values assigned to the toy seed-search candidates. See the Week 2 tool inventory for source paths, model limits, and checks.

Optional reading: CIGAR and reference positions

The CIGAR worked example takes 5–8 additional minutes outside the 180-minute core. Offer the link on slide 20 for reading after class.

Ask students to group ====X==DD===I=== and count consumption before opening the answer. The rows are reference ACGTACCGTTAC-GTA and query ACGTGCC--TACGGTA. They encode 4=1X2=2D3=1I3=: 14 query bases, 15 reference bases, 16 alignment columns. At SAM POS 101, the end is 115 inclusive, equivalent to Python [100:115] on the reference. The ungapped query stored in SEQ is ACGTGCCTACGGTA.

Useful checks: 2D consumes reference positions 108–109 with no query base; 1I consumes query base 11 between reference positions 112 and 113. M can represent either matching or differing bases; only = and X distinguish them. I/D describe the alignment relative to the reference, not an inferred evolutionary direction. The excerpt shows selected SAM fields, not a full record or parser. Use the primary SAM specification, section 1.4 for the full rules.

Ask where each query base would appear in a pileup. Then ask what further observations would help distinguish a real deletion from a sequencing or alignment error.

Common interpretation errors

An alignment difference can reflect variation, measurement error, or a misplaced read. Ask which scoring rule produced the alignment. Mapping a short read within a genome requires suitable start/end conditions; end-to-end global alignment against the entire genome would answer a different question. BLAST can miss candidates through heuristic filtering. Its E-value estimates a chance-hit count under a search model, not the probability that a particular hit is false. Shared ancestry and function require biological interpretation.

The search-evidence SVG is a separate, synthetic protein example: 9/10 identities = 90%, but only 10/20 query residues covered = 50%. Its coordinates are one-based inclusive. Label the switch from DNA letters to amino-acid letters before displaying it.

Homework handoff and key

The student notebook implements find_all, score_alignment, and the boundaries/recurrence of nw_table. Traceback and displays are supplied. Step 4 includes the AC/AG final-cell prediction from slide 18. Step 5 has a self-check on fitting alignment and candidate-window cell counts, with answers and no extra submitted task. Core work is estimated at 50 minutes, plus 10–40 minutes for setup, debugging, and interpretation. The reverse-complement extension takes additional time. Accept different optimal alignments if they preserve both sequences and have the same optimum; supplied code chooses diagonal, then up, then left.

Submission: notebook with prediction, all exact starts, the small DP table, printed fragment alignments, and three interpretation sentences. Ask them to explain a repeated placement, state the scoring rule, and identify one conclusion the alignment cannot support. Review common boundary and off-by-one mistakes at the start of week 3.

Review after teaching
