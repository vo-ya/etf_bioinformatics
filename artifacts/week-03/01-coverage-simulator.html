Sampling assumptions and limits

All reads have one fixed length, error-free and forward. Random draws independently choose an integer start uniformly from 0 through G−L, with replacement. This is a linear finite genome: end bases have fewer covering start positions than central bases. Uniform start sampling therefore does not make every base equally likely to be covered. The two preset arrangements are chosen examples, not random draws.

Repeated reads increase depth at the positions they cover, leaving other positions untouched. The simulation omits sequencing errors and sampling bias; it supplies read locations without assembling a sequence.
