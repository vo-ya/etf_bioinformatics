Week 01 / Introduction

Reading life as data

Two cultures of cells grow at different rates. What could explain the difference, and what would you measure? Begin with cells and DNA, then examine how a sequencing instrument produces reads. The homework uses quality scores to estimate errors in those reads.

Week 02 / Alignment and search

Sequence alignment and search

A read can match more than one place in a reference. Find its possible locations, then use alignment scores to compare sequences that differ. Test how gaps and search shortcuts affect the results.

180-minute class · seven interactive investigations · 32-slide presentation · separate 60–90-minute Colab homework

Week 03 / Sequence assembly

Reconstructing a sequence

Reconstruct a sequence from overlapping reads. Use a graph to track possible joins and see how repeated DNA can produce several reconstructions. Calculate N50 and examine why an incorrect join can increase it.

180-minute class · five interactive investigations · 40-slide presentation · separate 60–90-minute Colab homework

Week 04 / Guided Python and projects

From DNA letters to a picture

Build confidence with Python in class: run a short cell, predict a change, edit it, and explain the result. Turn a synthetic DNA string into a GC track, then choose a six-week project worth 30% of the final grade. Explore two full research examples and two full coding examples—a genome browser and an LLM question-answering tool—plus ten one-line alternatives, each scoped for about 24 hours per student.

180-minute workshop including the break · step-by-step notebook · project menu · separate 60–90-minute practice and planning
