Use these values throughout the toy examples: match +2, mismatch −1, each gap base −2. A linear gap of length k costs −2k. Lesson14

Global alignment accounts for both full sequences, including ends. Local alignment can leave flanking regions outside the alignment. Neither is universally preferable. End-free and other objectives also exist, especially in read-mapping contexts, but this class contrasts the two foundational cases. Source: NCBI BLAST glossary, global and local alignment definitions. NCBI glossary. Companion lesson.

Lesson16

With reference TTACGTAA and read ACGT, global alignment accounts for all eight reference bases, including four terminal gap columns in the read. Local alignment may select subsequences of both strings. Fitting alignment must consume the entire read but may start and stop within the reference, leaving its flanks unpenalized. Lesson27

Alignment length gives the scale of the identity comparison. Query coverage may refer to a single high-scoring segment or combined subject hits, so inspect the report field definition. Average coverage here means mean mapped read depth across the stated reference, including positions with zero reads. In the example, three four-base reads each align fully within a 12-base reference, giving 12/12 = 1×. Count bases aligned to reference positions, excluding clipped or inserted bases. A mean of 1× does not ensure every position is covered: all three reads could overlap the same four positions. This is a sequencing-dataset measure, distinct from query coverage in a search hit. Week 3 explores mean depth and covered fraction. Illumina: mean mapped read depth. E-value is an expected count of chance hits at least as strong under a statistical model and the search space. It is not the probability that this hit is false and it does not certify function. NCBI sequence-similarity statistics. NCBI output-field definitions. Companion lesson.

Lesson28

Start with the upper diagram: the query has 12 positions and the hit aligns positions 4–9, so query coverage is 6/12 = 50%. This counts included query positions, regardless of whether their letters match. The lower diagrams are separate synthetic read-mapping examples, not additional hits for the upper query. All three reads are four bases long and align fully within the 12-base reference, without gaps or clipping. Spread starts are 0, 4, and 8; clustered starts are 0, 0, and 0. Count the read bars above each position to obtain its depth. Average across all 12 reference positions, including zeros: spread gives twelve ones; clustered gives four threes and eight zeros. Both sums are 12, so both mean depths are 1×. Ask whether the same mean guarantees the same fraction of reference positions covered. The answer is no: breadth is 12/12 = 100% versus 4/12 ≈ 33.3%. Keep this reference breadth distinct from query coverage in the top diagram. The plot introduces the coverage-distribution example used in Week 3.
